# Screenshots

This directory is reserved for sanitized screenshots of the homelab.

Before uploading a screenshot, review it for:

- passwords
- client secrets
- Wazuh cluster keys
- Wi-Fi credentials
- private certificates
- API tokens
- unnecessary personal information

Suggested screenshots to add later:

1. Wazuh overview dashboard showing active agents and alert counts
2. Threat Hunting view filtered for Microsoft 365 events
3. Wazuh Office 365 events view
4. Docker Compose service status
5. Microsoft Purview Audit search results
6. Future Active Directory topology and detections

Use descriptive filenames such as:

```text
wazuh-overview.png
m365-office365-events.png
threat-hunting-office365.png
```

Do not upload raw screenshots that contain credentials.
