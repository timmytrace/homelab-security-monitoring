# Networking Portfolio — Cisco Packet Tracer

This section documents a structured networking lab series built in Cisco Packet Tracer as part of a cybersecurity and SOC-focused portfolio.

The goal is to build networking knowledge from first principles and progress toward a secure small-business enterprise network. Each lab includes design objectives, addressing, device configuration, verification, troubleshooting notes, and security relevance.

## Planned progression

1. **Lab 01 — Basic LAN, ARP, MAC Learning and ICMP**
2. Lab 02 — Routing Between Two Networks
3. Lab 03 — VLAN Segmentation
4. Lab 04 — Inter-VLAN Routing
5. Lab 05 — DHCP and DNS Services
6. Lab 06 — Access Control Lists
7. Lab 07 — NAT/PAT and Simulated Internet Access
8. Lab 08 — OSPF and Branch Connectivity
9. Lab 09 — Switch Security and Port Security
10. Capstone — Secure Small-Business Enterprise Network

## Portfolio objective

The networking track is designed to demonstrate practical understanding of:

- IPv4 addressing and subnetting
- Ethernet and MAC addressing
- ARP
- ICMP
- Layer 2 switching
- VLANs and trunking
- Routing and default gateways
- DHCP and DNS
- ACLs
- NAT/PAT
- OSPF
- switch hardening
- packet-level troubleshooting
- network documentation
- security segmentation

The networking labs complement the existing Wazuh/Microsoft 365 SOC homelab by strengthening the networking knowledge required for alert triage, packet analysis, segmentation, and incident response.
